Perguntas frequentes

Separamos as dúvidas mais comuns sobre o HRC Storage e o Check Replay.

O que é o HRC Storage?

É o espaço para guardar os arquivos .hrcz do HRC dentro das mãos compartilhadas no Check Replay. Quem abre o link vê o resultado do HRC junto com a mão.

Preciso ter o HRC para usar?

Para gerar o arquivo .hrcz, sim: o cálculo é feito no seu HRC. Para ver o resultado no link compartilhado, não.

Quem abre o link precisa rodar a mão de novo?

Não. O resultado já fica salvo dentro da mão, pronto para estudar.

Quantos arquivos posso subir por mão?

Até 8 arquivos .hrcz por mão.

Funciona para MTT e cash game?

O replayer funciona para cash, MTT e PLO. O HRC Storage guarda os arquivos .hrcz que você gerar no HRC.

O Check Replay é um solver?

Não. O Check Replay é um replayer para revisar e compartilhar mãos. Os cálculos vêm do HRC que você roda e sobe na mão.
